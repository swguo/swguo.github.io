實習課說明

課程名稱物件導向程式設計（實習）班級資訊二合
上課時間週四第 6、7 節教室資電118
對應正課IECS2073 物件導向程式設計授課方式中文／實體上機
請益時間週一第 8–9 節（15:10–17:00）、週三第 6–7 節（13:10–15:00）／資電 218／分機 3756

實習課承接前一日週三正課內容，以上機實作及主要作業為主。學生將正課所學應用於不同問題情境，獨立完成需求分析、UML、程式撰寫、測試與除錯。

教師或助教於課程開始時簡要說明作業規格，並以巡迴提示、個別指導及驗收為主；實習課不重複完整講授正課理論。

六份主要實習作業

  1. 封裝與類別設計
  2. 繼承與抽象類別
  3. 多型、介面與多載
  4. I/O、例外處理與資料存取
  5. 應用程式開發
  6. API 整合

部分作業跨兩週完成，主要工作原則上於實習課內完成。繳交內容依題目要求包含UML、原始碼、測試結果及必要說明。

期末專題與成果發表

專題由第12–14週的REST API整合作業逐步發展，不另增加全新題目。

  • 第15週：第1–6組發表；第16週：第7–12組發表。
  • 每組約15分鐘，包含簡報、UML／架構、實機展示及問答。
  • 12組均須於第15週實習課開始前繳交最終版，第16週發表組不得延後繳交或於繳交後修改。
  • 每位成員至少負責一項可辨識功能，並提交簡短個人貢獻說明。
  • 各組應準備備援展示影片；影片不能完全取代實機執行評量。

實習課規則

  1. 每週須攜帶已完成環境建置的筆電或使用電腦教室設備。
  2. 六份主要作業以個人獨立完成為原則；期末專題採分組合作。
  3. 個人作業不得直接交換或複製程式碼；引用外部或AI輔助內容須明確標示。
  4. 主要作業應依要求提交UML、原始碼、測試結果及必要說明。
  5. 程式無法執行、未依介面規格、缺少必要測試或涉及抄襲者，依規定扣分或以零分計。
