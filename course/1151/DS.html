課程說明

本課程以 Python 與真實資料為主軸，依序建立程式設計、NumPy 陣列運算、Pandas 表格處理、資料清洗、資訊視覺化與模型分析能力。學生將從原始資料出發，完成可重現的資料處理、問題導向分析、模型驗證與成果溝通。

10/06 教授 NumPy，10/13 教授 Pandas，10/20 教授資料清洗與資訊視覺化，10/27 串接探索式資料分析（EDA）全流程。期中聚焦資料處理、EDA 與圖表判讀；網路爬蟲順延至 11/10，其後進入統計推論與機器學習，並逐步完成期末專題。

課程採「概念短講＋操作示範＋漸進式 Lab＋結果討論」。實作須同時交付程式、處理依據與分析解釋，強調資料品質、可重現性與資料倫理。

授課時數：面授 48 小時＋非同步學習 6 小時，合計 54 小時。

課程目標

  1. 理解資料科學流程，能將實際問題轉換為可由資料回答的分析問題。
  2. 能透過公開 API 與網頁擷取資料，記錄來源與授權，建立可重現的資料取得流程。
  3. 能使用 Python 與 NumPy 進行陣列操作、布林篩選、向量化運算與數值摘要。
  4. 能使用 Pandas 讀取、篩選、整併、分組與重塑表格，處理型別、缺值、重複值與異常值。
  5. 能使用 Matplotlib、Seaborn 進行探索式分析，依問題選擇圖表，說明發現、限制與清洗決策。
  6. 能運用統計推論與 scikit-learn 建立迴歸、分類及分群模型。
  7. 能選用合適的評估指標，辨識資料洩漏、過度配適及模型限制。
  8. 能以可重現的 Notebook、圖表、口頭簡報及書面報告呈現分析成果。
  9. 能遵守資料隱私、著作權、研究倫理與生成式 AI 使用規範。

先備能力與學習環境

  • 建議具備基礎程式設計概念；第 3–4 週提供 Python 基礎與進階練習，銜接 NumPy、Pandas 實作。
  • 實作環境以 Google Colab／Jupyter Notebook 為主。
  • 主要套件：NumPy、Pandas（套件名稱 pandas）、Matplotlib、Seaborn、SciPy、scikit-learn；資料取得視需要使用 Requests、BeautifulSoup。
  • 主要參考書：Wes McKinney, Python for Data Analysis, 3rd Edition。
  • 補充教材：教師自編投影片、Notebook、公開資料集及指定閱讀。
