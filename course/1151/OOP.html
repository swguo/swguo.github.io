請益時間週一第 8–9 節（15:10–17:00）、週三第 6–7 節（13:10–15:00）／資電 218／分機 3756

本課程介紹物件導向程式設計的基本觀念、設計原則與實作方法，涵蓋封裝、繼承、多型、UML、例外處理、資料存取、Spring Boot、REST API、ORM、泛型與集合。

教學方式：每週三由教師帶領完成章節重點案例，從需求理解、UML、程式撰寫到執行與除錯，原則上於課堂內完成。

正實習銜接：週四實習課承接正課內容，另見物件導向程式設計實習課綱。

教學工具：Java SDK 17 LTS 以上、VS Code 或 IntelliJ IDEA、PlantUML 或 draw.io、Spring Boot。

課程目標

  1. 具備物件導向程式設計的基礎知識，理解封裝、繼承、多型與抽象化。
  2. 能以 UML 類別圖表達類別結構、責任與物件關係。
  3. 能閱讀、分析及撰寫具備物件導向特性的 Java 程式。
  4. 能使用資料存取與現代應用程式框架解決實務問題。
  5. 能從需求、設計、實作、測試與除錯完成一個可展示的系統。
